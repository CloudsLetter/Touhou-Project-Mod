该项目为 Touhou Project (整数作) 提供四项基础功能修改，目前仅包含 锁残、锁Bomb、满能量及锁定能量、无敌 等基础功能，当然不仅限于此，后续功能仍在开发中敬请期待。欢迎提交 PR 或 Issues 当然也可以给个 Star

使用 C# 编写，通过外部对应用内存R/W实现功能。支持浅/深色模式，中/英/日语言，除中文外其余语言均使用机器翻译，使用Visual Studio 2022 Preview 及 WPF开发，DONET 版本为8.0

非独立版本使用前需安装 DONET 8.0 运行时，下载地址: <https://dotnet.microsoft.com/zh-cn/download/dotnet/8.0>

注意三点：**每作的补丁表只对应一个确定的 exe 版本**（文件内已注明该版本的 timeStamp 与 textSize）—— 程序会在开启开关前读取游戏 exe 的 PE 头自动核对，版本不符时拒绝写入并在页面上提示；兽王园的两个 exe 版本（v1.00a / v1.10c）偏移不同，程序会自动识别并选用对应的一套；页面上只列出该作实际拥有的机制，没有的机制不会出现死开关。

东方红魔乡 新典（New Classic）是 2026 年的独立重制版，进程名 th06nc，与上面的老红魔乡是两个不同的可执行文件，两边可以各自单独修改。它是 64 位程序，请使用 x64 版本的程序（32 位版本读不到它的模块基址，开关会点不开）。
